# Proyecto Restaurante

Un sistema de restaurante pequeño, el cual nos permite asignar meseros, abrir mesas, tomar la orden (una comanda), calcular la cuenta con propina, poder dividirla entre los comensales y cerrar la mesa.

## Indice
- [Requisitos](#requisitos)
- [Instalacion](#instalacion)
- [Compilacion](#compilacion)

### Requisitos
- GCC
- make o mingw32-make

### Instalacion
``` bash
git clone https://github.com/WhosNoah/2026-2_Proyecto-Restaurante
cd 2026-2_Proyecto-Restaurante
```

### Compilacion
``` bash
make build
make link
make run
```
